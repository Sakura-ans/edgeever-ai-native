| 项目 | 修复行为 | 回归证据 |
| --- | --- | --- |
| F1 数据可靠性 | 未保存草稿与工作区分离保留；重读同步标题与输入框，不伪报保存；支持明确重试和放弃，关闭后可恢复 | 磁盘写入失败、版本冲突、重读、重启与重试；真实 IPC/文件 |

| F10 全中文安全错误 | 主进程、IPC、前端和 AI 使用稳定错误码；未知错误中文兜底；日志只记录操作与错误码 | 参数化错误测试、文件权限/磁盘/备份/加密/HTTP/工具/未知异常与脱敏 |

自动化：`bun run test`、`bun run typecheck`、`bun run build:web`；启动前端后运行 `node scripts/verify-personal-repairs.mjs`。Windows CI 从 cb001477 的 NSIS 安装包升级，运行既有回归与同一修复用例，并提供真实截图、逐项日志和相对该基线的字节审计。

草稿独立保存在应用的本机存储中，不冒充已写入工作区；若本机草稿存储也失败，会明确提示仅保留在内存。备份仍只包含已提交工作区，草稿可在提示栏查看复制。连续编辑分组令牌仅存在于当前进程，持久化的撤销/重做仍使用原备份格式。

本轮仅使用合成数据、mock SDK/本地 mock 提供方和临时测试用户目录，不使用真实密钥或付费请求。Windows CI 虚拟桌面不代表全部物理设备；组合输入事件测试不代表真人 Windows IME。自身回归完成后应由原独立评估会话复评，不能将自身测试称为独立验收。
